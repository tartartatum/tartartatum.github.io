READ-ONLY WHERE IT COUNTS — WHAT THIS APP WILL AND WILL NOT TOUCH
It will not add to or change your game files. Every file this app looks at is opened READ ONLY. Nothing is written back, renamed, moved or deleted.
Your in-game keybind list is never edited by the tablet. It only reads the newest layout_<name>_exported.xml in your GAME EXPORT FOLDER and measures everything against it. Your bindings inside Star Citizen are yours; this app has no way to alter them.
The only things it writes are PERIPHERAL BINDINGS — and only for the devices you tick above, and only when you run a builder. Each builder regenerates its own import file into its own folder; you then import that file using the peripheral's own software. Nothing else on your PC is touched, and your game files are never one of them.
Mouse and keyboard only? Tick nothing. With no peripherals selected there is nothing to build, and this app writes nothing at all beyond its own settings file. It becomes a pure read-only reference.
CONNECTING YOUR FILES (fresh machine / new user):
1. Game keybinds: in Star Citizen → Options → KEYBINDINGS → Advanced Customization → Control Profiles → save/export your profile. The game writes layout_<name>_exported.xml into …\StarCitizen\LIVE\user\client\0\controls\mappings inside YOUR install — paste that folder into GAME EXPORT FOLDER below. Everything is measured against the newest export there.
2. Tools folder: holds the sync engine (SC UPDATE ALL.bat / sc_sync.py) and MASTER_KEYBINDS.json. Migrating PCs = copy the whole folder across (USB / cloud / network share), then paste its new path below.
3. VoiceAttack: the regenerated SC Voice MFD <profile>.vap is written to the VOICEATTACK FOLDER. Import inside VoiceAttack: Profile menu → Import Profile → pick the .vap.
4. Stream Deck: import by double-clicking the <profile>_*.streamDeckProfile in the DECK PROFILE FOLDER with the Stream Deck app running.
5. Azeron: the regenerated AZERON_SC_KEYBINDS_<profile>.zip sits in the AZERON FOLDER. Azeron software → Profiles → Import → pick the zip.
NOTE: where the engine WRITES the .vap and deck profiles is set in Tools\sc_sync.py (CONFIG block at the top — open with Notepad). This page controls where the STATUS system READS from.
Reminder: the GAME EXPORT FOLDER above is read-only to this app — it is watched, never written. The builder folders for the peripherals you ticked are the only places anything is created, and only when you run a build.
