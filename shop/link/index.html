Command Deck EDGE Link

Free. The Command Deck widget for the Corsair XENEON EDGE needs this small Windows program to send your key presses to S.C. No account, no license key, no payment.

Ideas for the deck are welcome: every idea is read and considered. Post yours in the suggestions forum on Discord (serious suggestions only).

Download

Download Link 1.0.0 for Windows

Why you need it: the Command Deck widget runs inside iCUE, and iCUE widgets cannot press keys. The Link is the small program that does. Without it the deck shows "Start CmdGlas Command Deck EDGE Link on this PC".

78.8 MB. Windows 10 or 11, 64-bit. iCUE 5 with the Command Deck widget installed.

SHA-256: cd9ffcce86886f2550b1eb808c4e725bfcd0444c917559f588bcedb1b7b83710

Install

  1. Double-click the downloaded Setup file.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. Windows shows this for new programs that are not code-signed yet; the SHA-256 above lets you check the file is the one we published.
  3. The Link starts in the system tray (bottom-right, next to the clock) and starts with Windows from then on.
  4. In iCUE, set the Command Deck widget to size XL.
  5. The deck finds your S.C. keybinds by itself. To check or change them: right-click the tray icon and choose Keybinds…
  6. Run the game in borderless windowed mode, with the game window in front.

If a button does nothing

  1. Right-click the tray icon and choose Troubleshoot…
  2. Click RUN CHECKS. It checks the connection, the keybind file and the deck, and says what to fix.
  3. Still stuck: click COPY REPORT and send it from the support page. The report leaves out your Windows user name.

The Link only listens on this PC (127.0.0.1). It answers the Command Deck widget only and refuses web pages. It sends nothing over the internet.
