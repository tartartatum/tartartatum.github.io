Command Deck EDGE Link

Free. The Command Deck widget for the Corsair XENEON EDGE needs this small Windows program to send your key presses to S.C. No account, no license key, no payment.

Install

  1. Double-click the downloaded Setup file.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  3. The Link starts in the system tray (bottom-right, next to the clock) and starts with Windows from then on.
  4. In iCUE, set the Command Deck widget to size XL.
  5. The deck finds your S.C. keybinds by itself. To check or change them: right-click the tray icon and choose Keybinds…
  6. Run the game in borderless windowed mode, with the game window in front.

If a button does nothing

  1. Right-click the tray icon and choose Troubleshoot…
  2. Click RUN CHECKS. It checks the connection, the keybind file and the deck, and says what to fix.
  3. Still stuck: click COPY REPORT and send it from the support page. The report leaves out your Windows user name.
