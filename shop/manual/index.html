Command Deck manual

For the desktop version and the CORSAIR XENEON EDGE version. One purchase covers both.

Nothing found. Try one simple word, like key, backup or EDGE.

1. What you need

  • Desktop version: Windows 10 or 11, 64-bit. One screen is enough: the deck sits on top of the game and never takes focus away from it. A touch screen or second screen is optional.
  • XENEON EDGE version: iCUE 5.52 or later, the Command Deck widget, and the free Command Deck EDGE Link program on the same PC.
  • The game: set Window Mode to Borderless (Esc > Settings > Graphics), and have the game window in front when you tap.

No AI is downloaded or installed with any CmdGlas product. CmdGlas never changes your game files unless you press a button and confirm it.

2. Install and license key

  1. On the thank-you page after checkout, click Download. Later downloads: the downloads page with your key.
  2. Double-click the Setup file. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  3. The deck asks for your license key. Paste the key from the thank-you page and click Activate.

One key works on 2 PCs. Without internet the deck keeps working for 7 days, then asks you to connect once.

New PC: right-click the deck icon in the taskbar > Move license off this PC…, then enter the same key on the new PC.

3. Setup helper (about 3 minutes)

It opens by itself the first time. Open it again any time: right-click the deck icon in the taskbar > Setup helper…

  1. Game display mode: set the game to Borderless.
  2. Deck: screen: pick the screen, the size (Small, Medium, Large or Full) and how see-through the deck is.
  3. Deck: keybinds + test: the deck finds your saved game keybinds. Pick your show / hide key, choose 2 or 4 MFDs, then press TEST and click the game within 5 seconds: the deck sends your mobiGlas key once.

4. Using the deck

  • Tap a button and the game gets the key you already saved for that action. Nothing to type in.
  • Pages: flight, power and shields, MFD, combat, on-foot, mining, salvage, music and more.
  • Hold buttons (camera turns, boost) hold the key while your finger is down, for safety at most 5 seconds.
  • Protected buttons: SELF DESTRUCT and EJECT are in the EMERGENCY drawer and must be held for 1.5 s until the label shows CONFIRMED. RESPAWN also needs a 1.5 s hold. Lift earlier and nothing is sent.
  • Light bar (bottom centre): green = ready. Red = blocked: the game is not in front, or (EDGE) the Link is not running. Tap the gear above it for details.
  • Move the deck: drag the COMMAND DECK title.

5. Show / hide key (desktop)

Press your show / hide key while you play to show or hide the deck. It works with the game in front and never takes focus from it. Suggested key: Ctrl + Shift + D.

Change it later: right-click the deck icon in the taskbar > Setup helper… > Deck: keybinds > Record a different key, then press the new key. If the key ever stops working, the same taskbar menu has Show / hide Command Deck.

Why one or two modifiers, never three

Ctrl, Alt or Shift plus one key is quick to press in a fight. Three held modifiers plus a key is slow, easy to miss, and many keyboards drop one of four keys held at once. The deck does not accept a key with three modifiers.

Why no look-alike keys

The game can still see the keys you press. If your deck key is the same as, or very close to, a game key (for example Ctrl + D next to Ctrl + Shift + D), one press can do two things. That is why the deck has Key check, which finds clashes with your game keys, and FREE KEYS PICKER, which only picks combinations nothing else uses.

Keys the deck refuses

A single letter or number without Ctrl, Alt or Shift (it would fire while you type in chat), Alt + F4 (closes programs), number-pad keys with two modifiers, and any key with three modifiers. F keys work on their own.

6. Settings (the gear)

Tap the gear on the deck. DONE goes back to the deck; QUIT DECK closes it.

  • ACCENT: the light color of the deck.
  • DISPLAYS: 2 or 4 MFDs.
  • KEYBINDS: the keybind editor. It reads your saved game keybinds; change which key a deck button sends. Edits are saved in the deck only, never in the game file.
  • LAYOUT: new, rename, delete, reset or arrange button layouts, and save or load them as a file.
FREE KEYS PICKER: give every deck button a key
  1. Open the gear > FREE KEYS PICKER > FIND FREE KEYS. It lists deck buttons with no key in your game, each with a combination nothing uses (not your saved keys, not the game's standard keys; up to 2 modifiers + 1 key).
  2. Change any key, or untick a row to leave it out, then press CREATE FILE. Your own keybind file is never changed: the deck backs it up and writes a separate profile.
  3. In the game: Options > Keybindings > Advanced Controls Customization > Control Profiles, and load CmdGlas_FreeKeys. The deck reads the new keys by itself.
Key check: find key clashes

Right-click the deck icon in the taskbar > Key check…. It reads your game keys and shows where a deck key or the show / hide key clashes with one. It only reads; it never writes game files.

Game backup

Gear > GAME BACKUP > CHOOSE FOLDER (another drive, OneDrive or a USB stick) > BACKUP USER FOLDER. It copies your game's USER folder (keybinds, saved profiles, characters) and checks every file. Restore keybinds, characters or everything; the deck asks first, refuses while the game runs, and keeps an undo copy. The newest 10 backups are kept.

Taskbar menu

Right-click the deck icon (click ^ at the bottom right if you do not see it): Show / hide, Settings, Setup helper, Key check, Troubleshoot, Size, See-through, Keep on top of other windows, Move license off this PC, Check for updates, Quit.

7. XENEON EDGE version

  1. Install the free Command Deck EDGE Link. iCUE widgets cannot press keys; the Link does it. It starts in the tray and with Windows.
  2. In iCUE, add the Command Deck widget to the XENEON EDGE and set it to size XL.
  3. The Link finds your game keybinds by itself. To check them: right-click the Link tray icon > Keybinds…
  4. Run the game in Borderless, with the game window in front, and tap.

The Link only listens on this PC (127.0.0.1). It answers the Command Deck widget only and sends nothing over the internet. The EDGE has no show / hide key: it is its own screen.

8. If something does not work

A button does nothing

Look at the light bar. Red: click the game once so it is in front (EDGE: also check the Link is running). Then open the gear above the light bar > CHECK EVERYTHING, or the taskbar menu > Troubleshoot… > RUN CHECKS. It says what to fix.

The deck does not show over the game

The game must be in Borderless mode; full screen hides every other window. Then press your show / hide key, or use the taskbar menu > Show / hide Command Deck.

The show / hide key does nothing

Another program may use the same key. Record a different key in the Setup helper (section 5), then run Key check.

Still stuck

In the troubleshooter click COPY REPORT and send it from the support page. The report leaves out your Windows user name. Never post your license key in public.
